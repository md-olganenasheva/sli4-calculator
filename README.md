# SLI4 — калькулятор структурно-связочного фенотипа лонного сочленения

Веб-калькулятор для структурированной ультразвуковой оценки лонного сочленения и расчёта композитного индекса **SLI4 (0–4 балла)**.

Калькулятор предназначен для врачей ультразвуковой диагностики, акушеров-гинекологов и исследовательских групп, работающих с патологией лонного сочленения и лонно-тазовой дисфункцией.

## Что оценивает SLI4

Индекс формируется из четырёх компонентов:

- гипоэхогенные очаги в «ядре» межлобкового диска;
- гиперэхогенные включения / реверберации;
- связочный компонент — превышение заданного контрольного порога толщины верхней и/или передней лобковой связки;
- поражение «ядра» межлобкового диска более 50% по данным планиметрии.

Итоговый результат: **SLI4 = 0–4 балла**.

## Возможности калькулятора

- ввод клинического контекста исследования;
- автоматическая или ручная оценка степени поражения «ядра»;
- расчёт доли поражения по данным планиметрии;
- оценка верхней и передних лобковых связок;
- автоматический расчёт SLI4;
- формирование детализированного отчёта;
- копирование текстового отчёта;
- экспорт результата в JSON;
- печать результата;
- генерация анонимного идентификатора исследования.

Персональные данные пациентки в калькулятор вводить не требуется.

## Важное ограничение

SLI4 является инструментом структурированного ультразвукового фенотипирования и **не является самостоятельным клиническим диагнозом**.

Результат расчёта должен интерпретироваться совместно с:
- жалобами и клинической картиной;
- оценкой боли и функциональных ограничений;
- качеством ультразвуковой визуализации;
- данными динамического наблюдения;
- другими инструментальными и клиническими данными при наличии показаний.

Калькулятор **не определяет акушерскую тактику и способ родоразрешения самостоятельно**.
